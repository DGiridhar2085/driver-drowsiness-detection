# Driver Drowsiness Detection System

> **Status:** Academic-prototype reconstruction in progress.

A vehicle-safety prototype that explored Arduino-based sensing together with Python-based camera monitoring. The project combines physical sensing and facial-monitoring concepts to trigger a driver-warning response.

## Confirmed scope

- Arduino-based hardware component
- Pulse-rate and ultrasonic sensing
- Python-based camera/facial monitoring
- Warning-oriented prototype design

## Safety and accuracy note

This was an academic prototype, **not** a production or vehicle-certified safety system. Claims about accuracy, response time, facial-landmark models, or vehicle-throttle control will be added only after the reconstructed system is tested and measured.
